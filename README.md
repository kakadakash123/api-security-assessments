# DummyJSON REST API Security Assessment

## Project Overview

Conducted API security testing on the DummyJSON REST API to evaluate authentication, authorization, input validation, and request handling mechanisms.

## Scope

* Authentication Testing
* Authorization Testing
* Input Validation Testing
* Request Manipulation
* Response Analysis

## Tools Used

* Burp Suite Professional
* Postman

## Methodology

Assessment activities were performed following OWASP API Security Top 10 principles.

## Key Findings

* Authentication Control Review
* Authorization Validation
* Input Validation Assessment
* API Security Observations
